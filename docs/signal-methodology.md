# レポート総合判定仕様 v1

## 目的

メインページの「売られすぎ・中立・買われすぎ」は、テクニカル指標ではなく、公開済みの3レポートを総合して表示する。これは売買推奨ではなく、現在価格に対して期待とリスクがどの程度織り込まれているかを整理する参考判定である。

## 必須条件

次の3レポートがすべて完成し、検証に合格した銘柄だけ判定する。

1. 企業について
2. 現在の株価
3. 今後のカタリスト

いずれかが未完成、主要根拠が不足、価格基準日が不明、またはレポート間の数値が一致しない場合は、スコアを作らず「判定保留」とする。

## 内部スコア

内部スコアは0～100とする。数値は管理用であり、メインページには原則表示しない。

- 0に近い：期待に比べて現在価格が低い方向
- 50付近：上方向と下方向の材料が概ね均衡
- 100に近い：強い期待が現在価格へ入っている方向

総合スコアは次の加重平均で作る。

```text
総合スコア = 現在株価スコア × 0.60
            + カタリストスコア × 0.25
            + 企業基盤・リスクスコア × 0.15
```

すべての構成スコアは0～100へ正規化してから合算し、最後に小数第1位へ丸める。

## 1. 現在株価スコア（60%）

レポート②を使用する。現在株価がBear・Base・Bullのどこに位置するかを中心に、確率加重価格、希薄化、ネットデット、評価手法の不確実性を反映する。

- Bearを大きく下回る：0に近づける
- BearからBase：0～50の範囲
- Base付近：50前後
- BaseからBull：50～100の範囲
- Bullを大きく上回る：100に近づける

Bear・Base・Bullは同一の基準日、通貨、希薄化後株式数、評価期間で比較する。単純な直線補間だけでは重大リスクを表現できない場合、調整理由と根拠をレポート内に明記する。

## 2. カタリストスコア（25%）

レポート③を使用する。イベントの方向だけでなく、その期待が現在株価へどれだけ入っているかを評価する。

- 好材料が十分に織り込まれておらず、下振れより上振れ余地が大きい：0に近づける
- 上下の材料と織り込みが均衡：50前後
- 強い成功期待がすでに入り、失敗時の下振れが大きい：100に近づける

日付が不明な材料、根拠のない噂、重複するカタリストは加点・減点しない。複数イベントが同じ事業前提に依存する場合は独立イベントとして単純合算しない。

## 3. 企業基盤・リスクスコア（15%）

レポート①を使用する。企業の競争力、収益基盤、財務余力、希薄化可能性、顧客集中、規制・技術リスクを、現在の評価を支えられるかという観点で整理する。

- 強い競争力と財務余力があり、評価を支える根拠が厚い：0に近づける
- 強みとリスクが均衡：50前後
- 事業・財務の不確実性が高く、現在の期待を支える根拠が弱い：100に近づける

企業の知名度、株価の勢い、主観的な好みは採点根拠にしない。

## 表示区分

- 0.0～30.0：売られすぎ
- 30.1～69.9：中立
- 70.0～100.0：買われすぎ
- 必須条件を満たさない：判定保留

メインページのバー位置には内部スコアを使用するが、画面には区分名と分析基準日だけを表示する。

## `signals.json`の保存項目

判定済み銘柄は、銘柄IDをキーに次を保存する。

```json
{
  "position": 50.0,
  "zone": "中立",
  "asOf": "YYYY-MM-DD",
  "components": {
    "valuation": 50.0,
    "catalysts": 50.0,
    "businessRisk": 50.0
  },
  "reportRevision": "一意のレポート版識別子",
  "summary": "判定根拠の短い要約"
}
```

`zone`は計算済み`position`から機械的に決める。文章の印象だけで区分を上書きしない。

## 更新ルール

- 毎朝の株価更新では変更しない。
- 3レポートのいずれかを改訂したときに再計算する。
- 再計算時は3レポートをすべて再確認する。
- 基準株価と公開中の現在株価が大きく離れても、自動的に判定を変更しない。
- 古い判定には分析基準日を必ず表示する。
