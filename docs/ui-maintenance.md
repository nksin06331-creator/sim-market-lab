# 共通UIの保守

- トップページ: `assets/css/styles.css`、`assets/js/app.js`。
- レポート共通UI: `lab/assets/css/report-ui.css`。
- HTMLへの適用: `python scripts/apply_report_ui.py`。再実行しても重複しない。
- 共通レンダラーは生成時に適用する。外部テンプレートから別の方法で生成した場合も、公開前に上記コマンドを実行する。
- 適用後は `python scripts/validate_site.py` とPC・スマホの表示確認を行う。

UI変更では、分析値・総合判定・基準株価を更新しない。現在株価だけが更新されるため、固定の分析基準株価と騰落率の計算基準を並べて示す。3レポートは独立させ、それぞれ `../../index.html` への直接リンクを保つ。

一覧は初期表示。検索・市場・並び順・表示形式・スクロール位置はタブ単位のsessionStorageへ保存する。ストレージが利用できない環境でも基本操作は継続する。全市場では異なる通貨の株価順を無効にする。
